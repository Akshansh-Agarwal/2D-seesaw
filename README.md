# 2D-seesaw-simulation-engine

little physics project I made with tkinter. drop balls on a seesaw and watch it tip.

## how to run

```
python main.py
```

no installs needed, tkinter comes with python.

## controls

- click - drop a ball
- B - drop a heavy ball
- R or space - reset

## files

- `physics.py` - balls, gravity, bouncing, ball collisions
- `seesaw.py` - the plank and how it spins
- `main.py` - window, drawing, main loop

## stuff to mess around with

- change `GRAVITY` or `BOUNCE` at the top of physics.py
- make the plank longer in seesaw.py
- add a ball that's way heavier
